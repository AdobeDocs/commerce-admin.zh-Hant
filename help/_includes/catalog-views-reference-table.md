# 目錄檢視參考表格

網格會針對共用目錄同步到[!DNL Adobe Commerce Optimizer]時所建立的每個目錄檢視列出一列。 除了鍵指派動作之外，格線是唯讀的。 當聯結器同步Adobe Commerce中設定的共用目錄時，會自動建立及移除目錄檢視。 如果移除目錄，則在刪除對應的目錄檢視和資料之前會有[寬限期](/help/systems/catalog-view-sync-status.md#configure-the-deletion-grace-period)。

若要指派或取消指派受限制的存取金鑰，請參閱[指派金鑰給目錄檢視](/help/systems/restricted-access-keys.md#assign-keys-to-a-catalog-view)。

| 欄位 | 說明 |
| --- | --- |
| [!UICONTROL ACO Catalog View ID] | [!DNL Adobe Commerce Optimizer]中對應目錄檢視的識別碼。 請參閱[目錄檢視同步狀態摘要](/help/systems/catalog-view-sync-status.md#catalog-view-sync-status-summary)以檢查其同步處理狀況。 |
| [!UICONTROL Store View] | 目錄檢視代表的存放區檢視。 檢視[存放區檢視](/help/stores-purchase/store-views.md)。 |
| [!UICONTROL Access Keys] | 目前指派給目錄檢視的受限制存取金鑰的標題。 請參閱[受限制的存取金鑰管理](/help/systems/restricted-access-keys.md)。 |
| [!UICONTROL Actions] | 選取&#x200B;**[!UICONTROL Edit Restricted Access Keys]**&#x200B;以指派或取消指派目錄檢視的金鑰。 請參閱[將金鑰指派給目錄檢視](/help/systems/restricted-access-keys.md#assign-keys-to-a-catalog-view)。 |
